## Empfehlung zur Konsolidierung

Einige Mächte könnten **als Variante/Trapping** zu bestehenden Mächten geführt werden, statt eine neue Macht zu erstellen:

| Vorgeschlagene neue Macht | Stattdessen Variante von… | Begründung |
|---------------------------|--------------------------|------------|
| Heiliger Boden | `Schutz` | Zonen-Schutz, gleiche Mechanik |
| Liturgieschild | `Schutz` (göttliche Variante) | gleiche Mechanik |
| Gegengift | `Heilung` (Trapping) | nur Spezialfall |
| Spinnennetz | `Verstricken` | nur anderes Bild |
| Regenruf | `Wetterkontrolle` (Trapping) | nur Spezialfall |
| Blitzruf | `Teleportation` | Teleport |
| Wolfsform | `Böswillige Verwandlung` (Trapping) | nur eine Form |
| Finsternis | `Licht/Dunkelheit` | gegenteilig |
| Schnurren | (entfernen) | zu speziell |
| Göttliches Zeichen | `Mystisches Eingreifen` | bereits vorhanden! |
| Botenruf | `Gedankenverbindung` | ähnlich |

Durch Konsolidierung könnte die Zahl neuer Mächte von 40 auf ca. **15-20** reduziert werden.
